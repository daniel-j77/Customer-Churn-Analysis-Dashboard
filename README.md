# Customer Churn Analysis Dashboard

## Overview

Customer Churn Analysis Dashboard is an end-to-end data analytics project designed to analyze customer retention, subscription behavior, churn patterns, and key business performance indicators.

The project integrates Excel, SQL, Power BI, Python, and Streamlit to perform data cleaning, transformation, exploratory data analysis (EDA), and dashboard development. It provides valuable insights into customer churn trends, plan-wise retention rates, customer demographics, tenure analysis, and monthly revenue patterns.

The dashboard enables businesses to identify high-risk customer segments, understand factors influencing churn, and support data-driven retention strategies through interactive visualizations and KPI-driven reports.

## Features

* Data Cleaning
* SQL Analysis
* Customer Churn Analysis
* Churn Rate Calculation
* Plan-wise Churn Analysis
* Age Analysis
* Tenure Analysis
* Interactive Dashboard

## Tools

* Python
* Pandas
* SQLite
* Power BI
* Streamlit

## Dashboard Metrics

* Total Customers
* Churned Customers
* Churn Rate
* Average Monthly Charge
* Average Age
* Average Tenure

## Business Insights

* More than half of customers were identified as churned, indicating retention challenges.
* Customers with lower tenure showed a higher tendency to leave the service.
* Basic plan subscribers experienced higher churn rates compared to premium subscribers.
* Premium plan customers demonstrated stronger retention and longer customer lifecycles.
* Customer age and tenure patterns provided valuable indicators for retention-focused strategies.
